# 王颖个人数字花园主站 - 网站生成提示词

## 角色与目标

你是一位精通 2026 年国际前沿网页设计趋势的资深前端设计师与开发工程师。请根据以下要求，为我生成一个完整的、可直接运行的个人数字花园主站（Digital Garden Personal Website）。

核心关键词：**高级感、杂志感、国际化、中英混排、当代数字工作室风、精致微交互、克制色彩、功能完备**。

设计风格融合：
- 版本三「中英混排杂志版」：英文装饰标题 + 中文主标题 + 中英混排正文 + 彩色卡片
- 当代数字工作室风：设计感来自交互和排版本身，大胆字体组合、非对称平衡布局、精致微交互

参考气质：Pentagram 的杂志式滑动、Locomotive 的引入动效与文字微动效、Bakken & Baeck 的动效案例、Ditto 的视觉感觉。

## 设计哲学

### 整体气质

- **国际化杂志感**：像打开一本双语设计杂志，排版考究、留白充足、图文关系精致
- **当代数字工作室感**：像一个顶级创意工作室的官网，设计感来自字体、版式与微交互
- **克制的高级感**：不花哨、不堆砌，色彩克制，每个元素都有存在的理由
- **自然的中英混排**：英文作为装饰与辅助，中文作为核心信息，不翻译腔

### 设计语言

- **版式**：大量留白 + 非对称但平衡的布局 + 严谨的网格系统 + 杂志式图文关系
- **字体**：衬线字体（标题/装饰）+ 无衬线字体（正文/功能），中英各一组合
- **色彩**：黑白灰为主 + 一个低饱和主色 + 几个低饱和功能色
- **动效**：精致、柔和、有目的，不炫技。滚动触发、文字 reveal、hover 反馈、页面转场
- **交互**：自定义光标、磁吸按钮、卡片 tilt、平滑滚动

### 参考网站（请深刻理解其气质，不要复制，只借鉴）

- **Pentagram**：杂志式布局、横向滑动、文字与图片的精致关系
- **Locomotive**：引入动效、文字微动效、滚动体验
- **Bakken & Baeck**：丰富的动效案例、非对称布局、工作室感
- **Ditto**：视觉感觉、色彩搭配、卡片处理
- **Kinfolk / Cereal Magazine**：杂志留白、摄影驱动、编辑式设计

## 视觉系统（必须严格执行）

### 配色方案

采用一套克制、高级、具有国际杂志感的配色：

```css
:root {
  /* 背景 */
  --bg-primary: #faf9f6;       /* 暖白，主背景 */
  --bg-secondary: #f2f0eb;     /* 米灰，次级背景 */
  --bg-card: #ffffff;          /* 纯白卡片 */
  --bg-dark: #1a1a1a;          /* 深色区域 */

  /* 文字 */
  --text-primary: #1a1a1a;     /* 主文字 */
  --text-secondary: #6b6b6b;   /* 次要文字 */
  --text-muted: #9a9a9a;       /* 辅助文字 */
  --text-inverse: #faf9f6;     /* 深色背景上的文字 */

  /* 强调色 - 低饱和、高级 */
  --accent-terracotta: #c4a484;  /* 赭石/陶土，主强调色 */
  --accent-sage: #a8b5a0;        /* 鼠尾草绿 */
  --accent-lavender: #b8b3d3;    /* 淡薰衣草紫 */
  --accent-clay: #c78d7b;        /* 赤陶色 */

  /* 功能色 */
  --border: rgba(26, 26, 26, 0.08);
  --border-strong: rgba(26, 26, 26, 0.2);
  --shadow-soft: 0 4px 24px rgba(26, 26, 26, 0.05);
  --shadow-medium: 0 8px 40px rgba(26, 26, 26, 0.08);
}
```

**配色使用规则**：
- 页面 80% 以上保持黑白灰/暖白
- 彩色只用于小面积强调：导航高亮、标签、小卡片、hover 状态
- 不要使用高饱和度荧光色、霓虹色
- 深色模式可选，主模式为浅色

### 字体系统

**必须使用中英混排字体组合**：

```css
/* 标题/装饰字体 */
--font-display-en: "Playfair Display", "Canela", "Tiempos Headline", Georgia, serif;
--font-display-zh: "Source Han Serif CN", "Noto Serif SC", "方正兰亭宋", serif;

/* 正文/界面字体 */
--font-body-en: "Inter", "Suisse Int'l", "Helvetica Now", sans-serif;
--font-body-zh: "Source Han Sans CN", "Noto Sans SC", "PingFang SC", sans-serif;
```

**字体层级**：

```css
--text-hero-en: clamp(1rem, 2vw, 1.25rem);        /* 英文装饰小字 */
--text-hero-zh: clamp(3.5rem, 10vw, 8rem);        /* 中文主标题 */
--text-h1: clamp(2.5rem, 5vw, 4rem);
--text-h2: clamp(1.75rem, 3vw, 2.5rem);
--text-h3: clamp(1.25rem, 2vw, 1.5rem);
--text-body: clamp(1rem, 1.2vw, 1.125rem);
--text-small: 0.875rem;
--text-caption: 0.75rem;
```

**中英混排规则**：
- 英文只做装饰性小字（如 "DIGITAL GARDEN"、"SELECTED WORKS"）
- 中文做主标题和核心信息
- 中英文字混排时，英文字号比中文小 1-2 级
- 英文全部大写，字间距加大（letter-spacing: 0.1em - 0.2em）
- 中文标题字间距适度（letter-spacing: 0.05em）
- 行高：中文 1.6-1.8，英文 1.4-1.5

## 页面结构与功能要求

### 全局元素

#### 1. 导航栏

- 固定在顶部，滚动时背景从透明渐变为带模糊的暖白色（backdrop-filter: blur(12px)）
- 左侧：Logo「Wang Ying」或「王颖」，使用无衬线小字
- 右侧：导航链接（作品 / 笔记 / 兴趣 / 关于 / Now）
- 链接 hover：下划线从中心向两侧展开，或文字颜色变强调色
- 移动端：汉堡菜单，展开时有 stagger 淡入动画

#### 2. 自定义光标

- 默认：小圆点（8px）
- hover 链接/按钮：放大并变为空心圆（24px）
- hover 图片：显示 "View" 或 "查看" 文字
- hover 卡片：轻微磁吸效果
- 移动端禁用

#### 3. 滚动进度条

- 页面顶部一条细线（2px），随滚动填充
- 颜色使用强调色

#### 4. 页面切换转场

- 页面切换时：当前页淡出 + 新页从下方淡入
- 使用 React Router + Framer Motion AnimatePresence
- 时长 0.6s，缓动 cubic-bezier(0.16, 1, 0.3, 1)

#### 5. 返回顶部

- 右下角小圆按钮，滚动一定距离后出现
- hover 时轻微上浮

## 交互与动效要求（重点）

### 全局动效

1. **页面加载序列（参考 Locomotive）**
   - 页面从纯白渐入到内容
   - 文字从 opacity 0 + translateY(40px) 到正常
   - stagger 间隔 0.08s-0.12s
   - 时长 0.8s-1.2s
   - 缓动 cubic-bezier(0.16, 1, 0.3, 1)

2. **平滑滚动**
   - 全局 scroll-behavior: smooth
   - 使用 Lenis 或类似库实现丝滑滚动

3. **滚动触发动画**
   - 元素进入视口时淡入 + 上移
   - 使用 IntersectionObserver 或 GSAP ScrollTrigger
   - 触发阈值 0.1-0.2

4. **视差效果**
   - 大图有轻微视差（滚动速度 0.8-0.9 倍）
   - 文字有轻微反向视差

### 文字动效

1. **标题 reveal（参考 Locomotive）**
   - 标题从下方滑出，或从遮罩中 reveal
   - 逐字或逐行出现

2. **英文装饰文字**
   - 页面加载时字间距从宽到正常
   - 或从 opacity 0 淡入

3. **hover 动效**
   - 链接 hover：下划线从中心展开
   - 按钮 hover：文字轻微上移，下方出现强调色
   - 标题 hover：字符间距轻微增大

### 卡片与按钮交互

1. **磁吸按钮（Magnetic Button）**
   - 鼠标靠近时按钮轻微向鼠标方向移动
   - 最大移动距离 10-15px
   - 离开时弹性复位

2. **卡片 3D Tilt**
   - 鼠标在卡片上移动时轻微倾斜
   - 最大角度 5-8 度
   - 使用 perspective(1000px)

3. **卡片 hover**
   - translateY(-6px)
   - 阴影加深
   - 内部图片 scale(1.03)

### 特殊动效

1. **Pentagram 式横向滑动**
   - 作品集项目列表可横向滑动切换
   - 或项目详情页使用横向转场
   - 滑动时有惯性、有边界反馈

2. **3D 文字轻微旋转**
   - 首页大标题根据鼠标位置有极其轻微的 3D 旋转
   - 最大旋转 2-3 度，几乎不可察觉但能感觉到"活"

3. **图片 reveal**
   - 图片进入视口时，从遮罩中向上 reveal
   - 或从模糊到清晰

4. **光标跟随的局部效果**
   - 大图片 hover 时出现查看提示
   - 卡片 hover 时出现相关图标
