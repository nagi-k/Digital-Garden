# 王颖个人主站规划文档

## 一、项目定位

打造一个以个人为中心的 **数字花园（Digital Garden）**：
- 不是传统简历式作品集
- 也不是单一博客
- 而是一个持续生长、展示「你是谁、你做了什么、你在学什么、你喜欢什么」的个人网络空间

核心气质：**设计师的个人主页 + 作品集 + 学习记录 + 兴趣爱好** 的融合体。

---

## 二、整体架构

采用 **子路径方式** 部署在同一个域名下，避免每次新增内容都重复备案：

```
wangying.online/
├── /              ← 个人主页（入口汇总）
├── /ui/           ← UI/UX 作品集（当前已完成的网站）
├── /notes/        ← 学习记录、设计思考、读书笔记
├── /interests/    ← 兴趣爱好（电影/音乐/书籍/旅行/摄影等）
├── /about/        ← 关于我
├── /now/          ← 现在在做什么
├── /uses/         ← 工具箱（可选）
└── /guestbook/    ← 访客留言墙（可选）
```

> 备案期间先使用 CloudBase 默认域名访问，备案通过后切换至 wangying.online。

---

## 三、各页面内容规划

### 1. 首页 /

功能：让人一眼知道你是谁，并引导到各个板块。

建议包含：
- 大标题 + 一句话自我介绍
- 个人头像
- 简短 bio（2-3 句话）
- 导航卡片：作品集 / 学习记录 / 兴趣爱好 / 关于我
- 最近更新区域（最近一篇笔记、最近在看的书等）
- 社交链接（微信 / 邮箱 / Behance / Dribbble 等）

风格方向：
- 简洁但有设计感
- 可以有 1-2 个精心设计的微交互
- 避免过度炫酷影响加载速度

---

- 返回首页的导航

### 3. 学习记录 /notes/

不是按时间排列的博客列表，而是可视化成长时间线 + 笔记集合。

内容形式：
- 时间线：2026 年 8 月学了 Figma 自动布局，9 月做了第一个动效…
- 文章/笔记卡片
- 标签分类（Figma / 交互设计 / 设计系统 / 用户体验 / AI 工具等）
- 可搜索、可筛选

内容来源：
- 学习新工具的心得
- 读书/看课笔记
- 项目复盘
- 设计方法总结

参考风格：Maggie Appleton 的数字花园、Andy Matuschak 的网状笔记。

---

### 4. 兴趣爱好 /interests/

用设计师的方式展示个人生活，不是简单文字列表。

建议板块：
- **视觉灵感板 Mood Board**：喜欢的配色、摄影、建筑、艺术作品
- **最近在迷**：最近看的一部电影 / 一本书 / 一张专辑 / 一个展览
- **收藏夹**：
  - 喜欢的电影（海报墙）
  - 喜欢的音乐（专辑封面墙）
  - 喜欢的书（书籍封面墙）
  - 喜欢的设计师/工作室
- **旅行手帐**：去过的地方 + 照片 + 简短感受
- **10 things I love**：一个精选列表

视觉形式：卡片网格、瀑布流、封面墙。

---

### 5. 关于我 /about/

内容：
- 更详细的个人故事
- 设计经历
- 设计理念/原则
- 职业目标
- 联系方式

设计：可以放一张生活照，增加真实感。

---

### 6. Now 页面 /now/

国外很流行的页面，展示「我现在在做什么」。

内容定期更新：
- 正在学的技能
- 正在做的项目
- 最近在思考的问题
- 当前使用的工具
- 最近的生活状态

更新频率：每月或每季度。

---

### 7. 工具箱 /uses/（可选）

列出你使用的工具：
- 设计软件：Figma / Sketch / Principle / ProtoPie
- 效率工具：Notion / Obsidian / 语雀
- 硬件设备
- 灵感来源网站

---

### 8. 访客留言墙 /guestbook/（可选）

一个有趣的互动功能：
- 访客可以留言
- 留言以视觉化形式展示在墙上
- 长期积累变成一幅集体作品

## 四、设计方向建议

### 整体风格

- 简洁、现代、有设计师气质
- 统一的配色和字体系统
- 克制但有记忆点的动效
- 移动端优先

### 推荐加入的创新元素

1. **把网站本身当作作品**：首页或某个页面做成可交互的演示
2. **学习可视化时间线**：用进度条/时间轴展示成长
3. **Now 页面**：增加鲜活感
4. **兴趣封面墙**：用视觉化方式展示爱好
5. **微交互设计**：hover 效果、页面切换动效、滚动动画

### 避免

- 过度 3D 或炫酷导致加载慢
- 内容太少却页面太多
- 为了设计而设计，影响可读性

---

## 五、技术方案

- 前端框架：React + Vite + TypeScript + Tailwind CSS（复用现有技术栈）
- 部署：腾讯云 CloudBase 静态网站托管
- 域名：wangying.online
- 图片存储：腾讯云 COS
- 内容管理：JSON 配置文件（当前方案）或后续升级为 CMS
